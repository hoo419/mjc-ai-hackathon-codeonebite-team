# 새 컴퓨터로 작업 이관 가이드

이 저장소는 **공개(public) 저장소**라서, 진짜 비밀값(API 키/DB 접속 정보)은 절대 git에 올리지 않는다.
그래서 git clone만으로는 앱이 바로 안 돌아간다 — 아래 "직접 옮겨야 하는 파일"을 별도로 옮기고,
"설치해야 하는 환경"을 새 컴퓨터에 준비해야 한다.

## 1. 직접 옮겨야 하는 민감한 파일 (git에 없음, USB/개인 메신저 등으로 직접 전달)

### `backend/.env`
`.gitignore`에 의해 git에서 완전히 제외되어 있다. 아래 키들의 **실제 값**이 들어있다:

| 변수명 | 용도 |
|---|---|
| `AI_API_BASE_URL` | FactChat(Mindlogic) AI 게이트웨이 주소 |
| `AI_API_KEY` | 위 AI 게이트웨이 API 키 |
| `AI_MODEL` | 사용할 모델명 (예: gpt-5.4-mini 계열) |
| `DATABASE_URL` | Neon PostgreSQL 접속 문자열 (비워두면 Mock JSON 모드로 동작) |

값이 뭔지는 템플릿 파일 `backend/.env.example`(git에 포함됨)을 보면 어떤 키가 필요한지는 알 수 있지만
실제 값은 적혀있지 않다. **절대 이 파일 내용을 그대로 커밋하거나 채팅/이슈/PR 등 공개된 곳에 붙여넣지 말 것.**

### `frontend/.env.local`
민감한 값은 아니지만(로컬 API 주소일 뿐) 마찬가지로 git에 없어서 새 컴퓨터에서 직접 만들어야 한다.
`frontend/.env.local.example`을 그대로 복사해서 써도 무방하다 (기본값이 `http://localhost:8000/api`).

### (참고) GitHub 인증
저장소를 push하려면 새 컴퓨터에도 GitHub 로그인(HTTPS는 Personal Access Token, 또는 SSH 키)이 별도로 설정되어 있어야 한다.
이것도 git에 담기는 값이 아니라 컴퓨터별로 따로 설정하는 것.

## 2. 새 컴퓨터에 설치해야 하는 환경

| 도구 | 버전 | 비고 |
|---|---|---|
| Git | 아무 최신 버전 | 저장소 clone/push용 |
| Node.js | 20 LTS 이상 (작업 환경은 v24.15.0 사용) | frontend(Next.js 16) 구동용 |
| Python | 3.11 이상 (작업 환경은 3.14.4 사용) | backend(FastAPI) 구동용 |
| (선택) GitHub CLI (`gh`) | 최신 | PR/이슈 다룰 때 편함 |

PostgreSQL을 로컬에 따로 설치할 필요는 없다 — `DATABASE_URL`이 가리키는 Neon은 클라우드 호스팅이라
인터넷 연결만 있으면 그대로 붙는다. `DATABASE_URL`을 비워두면 자동으로 `data/*.json` 기반 Mock 모드로 동작한다.

## 3. 저장소 받고 실행하는 순서

```bash
git clone https://github.com/hoo419/mjc-ai-hackathon-codeonebite-team.git
cd mjc-ai-hackathon-codeonebite-team
git checkout integration/fullstack-demo
```

### Backend

```bash
cd backend
python -m venv .venv
# Windows: .venv\Scripts\activate  /  macOS·Linux: source .venv/bin/activate
pip install -r requirements.txt
# 이 자리에 위 1번에서 직접 옮긴 .env 파일을 붙여넣는다
uvicorn app.main:app --reload --port 8000
```

### Frontend

```bash
cd frontend
npm install
# .env.local이 없으면 .env.local.example을 복사해서 사용
npm run dev
```

프론트는 `http://localhost:3000`, 백엔드는 `http://localhost:8000`에서 뜬다.
